# AppServiceAzure

Proyecto web ASP.NET Core preparado para despliegue en Azure App Service.

## Estructura del Proyecto

- `AzureWeb/`: Aplicación ASP.NET Core MVC.
- `AzureWeb.slnx`: Solución del proyecto.

## Requisitos

- [.NET 10 SDK](https://dotnet.microsoft.com/) o superior.

## Ejecución local

```bash
dotnet restore
dotnet run --project AzureWeb/AzureWeb.csproj
```
